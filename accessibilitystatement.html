Accessibility Statement

Standards

We have designed this site with accessibility in mind, including:

  • Semantic HTML — proper headings, landmarks, and form structure so screen readers can navigate the page logically.
  • Form labels — every input has an associated <label> so assistive technology can announce what each field is for.
  • Grouped form controls — fieldsets and legends organize related inputs (personal details, order preferences, contact options) into meaningful sections.
  • Keyboard navigation — all interactive elements (links, inputs, radio buttons, checkboxes, the submit button) can be reached and operated using a keyboard alone.
  • Visible focus indicators — focused form fields show a clear border and highlight so keyboard users can see where they are.
  • Sufficient color contrast — text and interactive elements meet or exceed WCAG 2.1 AA contrast ratios.
  • Descriptive link text — navigation links are labeled clearly (e.g., "HOME", "CONTACT / ORDER") rather than "click here".
  • Responsive layout — the page reflows sensibly on small screens and at high zoom levels.

Standards we aim for

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA. These guidelines explain how to make web content more accessible to people with a wide range of disabilities.
